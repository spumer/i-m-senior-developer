# AI Prose Detector

Инструмент для редактирования художественной прозы с фокусом на выявление 
паттернов AI-генерации.

## Философия

Цель — не механически искать "запрещённые слова", а понимать ПРИНЦИПЫ, 
по которым AI создаёт синтетический текст, и выявлять их проявления.

Каждый приём МОЖЕТ быть оправдан контекстом. Задача — найти места, где 
приём НЕ РАБОТАЕТ на текст.

## Порядок работы

### 1. Определи контекст

Перед анализом уточни:
- **POV:** Первое лицо? Третье ограниченное? Всеведущее?
- **Жанр:** Триллер, киберпанк, лирическая проза?
- **Сцена:** Экшн, диалог, рефлексия?

Это влияет на допустимость приёмов.

### 2. Прочитай текст целиком

Не начинай анализ по частям. Сначала — общее впечатление:
- Где текст "застревает"?
- Где кажется механическим?
- Где читатель выпадает?

### 3. Пройди по методам

Для каждого метода загрузи соответствующий файл из `references/` 
и примени тесты к подозрительным местам.

### 4. Используй формат диагноза

Для каждой найденной проблемы:
```
- НАЙДЕНО: [цитата]
- ТИП: [категория из метода]
- ТЕСТЫ: [результаты применимых тестов]
- ВЕРДИКТ: Проблема / Допустимо / Спорно
- НАПРАВЛЕНИЕ: [принцип исправления, не готовое решение]
```

### 5. Составь итоговый отчёт

```
### КРИТИЧЕСКИЕ ПРОБЛЕМЫ
[Требуют обязательного исправления — структурные, повторяющиеся]

### РЕКОМЕНДАЦИИ  
[Можно улучшить — локальные, не критичные]

### СИЛЬНЫЕ МЕСТА
[Где автор избежал AI-штампов — для понимания его сильных сторон]

### ОБЩАЯ ОЦЕНКА
[2-3 принципа, требующие наибольшего внимания]
```

## Жанровая настройка: Триллер / Киберпанк

Текущий skill настроен на:
- Технологическая конкретика > поэтичность
- Напряжение > красота
- Физиологичность > элегантность
- Высокое доверие к читателю (минимум объяснений)

Для других жанров — адаптируй критерии.

## Принципы критики

1. **Не ищи слова — ищи паттерны.** "Почувствовала" может быть проблемой 
   или инструментом. Решает контекст.

2. **Функция важнее формы.** Приём оправдан, если служит эффекту.

3. **Направление, не готовое решение.** Исправления может дать только 
   автор, знающий полный контекст.

4. **Спорные случаи — вопросы автору.** Не выноси вердикт, если 
   не уверен. Сформулируй вопрос.

5. **Ищи сильные места тоже.** Понимание того, что работает, 
   помогает понять, что нет.

## Быстрый чеклист

Для экспресс-проверки абзаца:

- [ ] Есть ли цепочки глаголов восприятия? (М1)
- [ ] Есть ли клише типа "город проглотил"? (М2)
- [ ] Детали физически возможны в этих условиях? (М3)
- [ ] Эмоция показана, а потом названа? (М4)
- [ ] Есть ли переходы между эмоциональными состояниями? (М5)
- [ ] Длина предложений варьируется? (М6)

## Ограничения

Этот инструмент:
- НЕ заменяет редактора-человека
- НЕ даёт готовых исправлений (только направления)
- НЕ подходит для всех жанров без адаптации
- НЕ является детектором "AI vs человек" (человек тоже может писать клише)

Цель — улучшить текст, а не вынести приговор.
