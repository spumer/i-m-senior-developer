# МЕТОД 5: ИГНОРИРОВАНИЕ ФИЗИОЛОГИИ (МЕХАНИСТИЧНЫЙ ПЕЙСИНГ)

## ПРИНЦИП

AI знает, что персонаж "в стрессе", но не понимает, как стресс работает 
физически. Реальное тело:
- Не переключается между эмоциями мгновенно
- Имеет инерцию (адреналин не исчезает по команде)
- Оставляет следы (дрожь, сухость во рту, потливость)

AI-текст часто описывает эмоции как переключение тумблера: 
паника → спокойствие → ярость — без переходов и последствий.

---

## ФИЗИОЛОГИЯ СТРЕССА: СПРАВОЧНИК

### Острый стресс (fight-or-flight)

**Что происходит в теле:**
| Система | Реакция | Как описать |
|---------|---------|-------------|
| Сердце | Учащённое сердцебиение | "Сердце билось в горле", "пульс в ушах" |
| Дыхание | Поверхностное, учащённое | "Не хватало воздуха", "дышала ртом" |
| Мышцы | Напряжение, готовность | "Плечи каменные", "челюсть свело" |
| Руки | Тремор, холодный пот | "Руки не слушались", "пальцы скользили" |
| Рот | Сухость | "Язык как наждак", "не могла сглотнуть" |
| Зрение | Туннельное, фокус на угрозе | "Периферия исчезла", "только его лицо" |
| Слух | Приглушённость или обострение | "Звуки как из-под воды", "каждый звук — удар" |
| Время | Субъективное ускорение | "Всё происходило слишком быстро" |

### После острого стресса (отходняк)

**Что происходит в теле (30 сек — 30 мин после):**
| Система | Реакция | Как описать |
|---------|---------|-------------|
| Мышцы | Слабость, дрожь | "Ноги не держали", "колени подогнулись" |
| Руки | Продолжающийся тремор | "Руки ходили ходуном" |
| Желудок | Тошнота | "Накатила тошнота", "желудок сжался" |
| Голова | Головокружение | "Стены поплыли", "пришлось схватиться за стену" |
| Голос | Срывающийся, хриплый | "Голос сел", "слова не шли" |
| Эмоции | Отложенная реакция | "Она заплакала только через час" |

## ТИПОЛОГИЯ НАРУШЕНИЙ ФИЗИОЛОГИИ

### ТИП A: МГНОВЕННОЕ ПЕРЕКЛЮЧЕНИЕ

Персонаж меняет эмоциональное состояние без переходного периода.

```
Плохо:
"Она была в панике. Потом взяла себя в руки и спокойно продолжила работу."
```

**Почему плохо:** Адреналин не исчезает по команде. "Взять себя в руки" — 
не кнопка, а процесс с физическими артефактами.

```
Лучше:
"Паника схлынула, но руки ещё дрожали. Она попыталась набрать код — 
не с первого раза. Не со второго."
```

---

### ТИП B: "ПРОФЕССИОНАЛЬНОЕ СПОКОЙСТВИЕ"

AI-троп: персонаж в стрессе внезапно становится невозмутимым, потому что он 
"профессионал". Это работает только в определённых условиях.

```
Плохо:
"Её чуть не убили. Но она была тренированным агентом, 
поэтому голос не дрогнул."
```

**Почему плохо:** Даже тренированные люди испытывают физиологические 
реакции. Тренировка позволяет ДЕЙСТВОВАТЬ несмотря на них, но не отменяет их.

```
Лучше:
"Голос не дрогнул — это было вбито тренировкой. Но руки она убрала 
под стол, чтобы не было видно, как трясутся пальцы."
```

---

### ТИП C: ОТСУТСТВИЕ ОТХОДНЯКА

После интенсивной сцены персонаж продолжает действовать как ни в чём не бывало.

```
Плохо:
"Перестрелка закончилась. Она встала и пошла к выходу."
```

**Почему плохо:** После выброса адреналина тело требует времени 
на восстановление. Минимум — тремор, слабость в ногах.

```
Лучше:
"Перестрелка закончилась. Тишина была громче выстрелов. 
Она попыталась встать — ноги не слушались. Со второй попытки — 
держась за стену."
```

---

### ТИП D: АНТИТРОП "РУКИ НЕ ДРОЖАЛИ"

AI часто использует "руки не дрожали — это было странно" как способ 
избежать описания дрожи. Это meta-отсылка, которая не даёт сенсорного опыта.

```
Плохо:
"Руки не дрожали. Это было странно."
```

**Почему плохо:** Читатель получает отрицание, а не образ. 
Кроме того, это клише.

```
Лучше:
Вариант 1 (если реально не дрожат — шок): 
"Руки двигались отдельно от неё, как чужие."

Вариант 2 (если должны дрожать):
"Руки ходили ходуном. Вставить ключ в замок — три попытки."
```

---

### ТИП E: НЕСООТВЕТСТВИЕ ИНТЕНСИВНОСТИ

Физиологическая реакция не соответствует уровню угрозы.

```
Плохо (недостаточно):
"Ей приставили нож к горлу. Её сердце забилось чуть быстрее."
```

```
Плохо (избыточно):
"Она увидела неприятного коллегу. Адреналин хлынул в кровь, 
зрачки расширились, мышцы напряглись."
```

**Правило:** Калибруй физиологию под угрозу.

## ВРЕМЕННЫ́Е РАМКИ ФИЗИОЛОГИИ

```
ОСТРАЯ ФАЗА (0-30 сек):
Максимальная интенсивность. Туннельное зрение, притуплённая боль,
замедленное восприятие времени (субъективно).

АДАПТАЦИЯ (30 сек - 5 мин):
Тело адаптируется к стрессу. Возможны целенаправленные действия,
но физиология не нормализуется.

ОТХОДНЯК (5-30 мин после):
Адреналин выгорает. Дрожь, слабость, тошнота, эмоциональные колебания.
"Самое худшее — это когда всё закончилось."

ОТЛОЖЕННАЯ РЕАКЦИЯ (часы-дни):
Бессонница, флэшбеки, повышенная тревожность. 
Для триллера: "Она проснулась от стука сердца — комната была пуста."
```

## ТЕСТЫ НА ФИЗИОЛОГИЧНОСТЬ

```
1. ТЕСТ ПЕРЕХОДА
   Есть ли "мост" между эмоциональными состояниями?
   ДА → физиология учтена
   НЕТ → добавить переходную фазу

2. ТЕСТ АРТЕФАКТОВ
   Остаются ли следы стресса после пиковой сцены?
   ДА → реалистично
   НЕТ → добавить отходняк

3. ТЕСТ КАЛИБРОВКИ
   Физиология соответствует уровню угрозы?
   СООТВЕТСТВУЕТ → ок
   НЕ СООТВЕТСТВУЕТ → подрегулировать интенсивность

4. ТЕСТ СЕНСОРНОСТИ
   Физиология описана через ощущения или просто названа?
   ЧЕРЕЗ ОЩУЩЕНИЯ → хорошо
   НАЗВАНА ("она нервничала") → заменить на показ
```

## ФОРМАТ ДИАГНОЗА

```
- НАЙДЕНО: [цитата или описание перехода]
- ТИП: Мгновенное переключение / Профессиональное спокойствие / 
       Отсутствие отходняка / Антитроп / Несоответствие интенсивности
- КОНТЕКСТ: [что произошло до, какой уровень угрозы]
- ТЕСТЫ:
  • Переход: [есть ли мост]
  • Артефакты: [остались ли следы]
  • Калибровка: [соответствует ли]
  • Сенсорность: [показано ли]
- ВЕРДИКТ: Проблема / Допустимо
- ЕСЛИ ПРОБЛЕМА — НАПРАВЛЕНИЕ: [какую физиологию добавить, 
                                какой переход создать]
```

## ПРИМЕРЫ ДИАГНОСТИКИ

**Пример 1: Мгновенное переключение**
```
НАЙДЕНО: "Она дрожала от страха. В следующую секунду её голос 
          был холоден и ровен."
ТИП: Мгновенное переключение
КОНТЕКСТ: Угроза жизни, затем переговоры
ТЕСТЫ:
  • Переход: НЕТ — скачок без моста
  • Артефакты: НЕТ — дрожь исчезла
  • Калибровка: Угроза высокая, реакция должна быть долгой
ВЕРДИКТ: Проблема
НАПРАВЛЕНИЕ: "Голос был ровен — она заставила. Но горло сжималось, 
              и каждое слово требовало усилия."
```

**Пример 2: Допустимый антитроп**
```
НАЙДЕНО: "Руки не дрожали. Он удивился — после такого должны."
ТИП: Антитроп "руки не дрожали"
КОНТЕКСТ: Персонаж в шоке после аварии
ТЕСТЫ:
  • Сенсорность: Частично — есть рефлексия персонажа
ВЕРДИКТ: Спорно — если это ШОКОВОЕ ОЦЕПЕНЕНИЕ, может работать
ВОПРОС АВТОРУ: Это диссоциация? Если да, можно усилить: 
               "Руки не дрожали. Он смотрел на них как на чужие."
```

**Пример 3: Хорошая физиология**
```
НАЙДЕНО: "Адреналин ушёл, оставив мелкую противную дрожь. 
          Она прислонилась к стене — ноги отказывали. 
          Во рту — вкус меди, как будто прикусила язык."
ТИП: —
ТЕСТЫ: Все пройдены
ВЕРДИКТ: Допустимо — физиология подробная и сенсорная
КОММЕНТАРИЙ: Сильный пассаж, можно использовать как эталон
```

## ОСОБЫЙ СЛУЧАЙ: ХРОНИЧЕСКОЕ НАПРЯЖЕНИЕ

В триллере персонаж может находиться в состоянии стресса ДНЯМИ. 
Это отличается от острого стресса:

**Хронический стресс:**
- Бессонница или беспокойный сон
- Потеря аппетита или переедание
- Постоянное фоновое напряжение мышц (боль в шее, спине)
- Раздражительность на мелочи
- Рассеянность, трудности с концентрацией
- "Подпрыгивание" от обычных звуков

```
Пример:
"Третий день без сна. Кофе больше не работал — только усиливал 
дрожь в руках. Звонок телефона заставил её подпрыгнуть."
```
