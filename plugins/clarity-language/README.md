# Clarity Language Plugin

Ясность языка — три скилла против AI-синтетики в текстах. От смысловой
консистентности технических документов до естественности русской фразы.

## Что это

Три дополняющих друг друга скилла. Каждый ловит свой класс «синтетики» — следов того,
что текст писала модель, а не человек:

| Скилл | Что ловит | Где применять |
|-------|-----------|---------------|
| **clarity-validator** | 12 **смысловых** AI-паттернов: смешение когнитивных слоёв, противоречия между файлами, выдуманный флоу, negation of nothing, leaked invariants, имитация авторитета через цифры. С FPF-обоснованием (A.7, A.10, A.1.1, A.11). | Технические документы, гайды, спеки |
| **ai-prose-detector** | **Стилистические** AI-паттерны в художественной прозе: дистанция от опыта, готовые метафоры, галлюцинации деталей, переобъяснение, механистичность, монотонность ритма (6 методов). | Беллетристика — триллер, киберпанк, напряжённая проза |
| **russian-style** | **Естественность** русской фразы: англо-кальки («сигнал», «прокси»), придуманные русские переводы устоявшихся заимствований («живость» вместо «хелсчека»), пустые антитезы «не X, а Y», канцелярит и хедж, подставленное AI-панибратство, рассогласование, оставшееся после замены термина («один … фича»). | Любые русскоязычные тексты — доки, скрипты, реплики |

Разница в одной строке: `clarity-validator` — что _утверждается_ и _как структурировано_;
`ai-prose-detector` — как _написана_ художка; `russian-style` — звучит ли фраза
по-русски естественно.

## Что получаете при установке

- **SessionStart hook** — Plain Language Gate: правило, применяемое перед каждой записью
  человекочитаемого текста (планы, решения, сводки, отчёты), а не разовое напоминание на
  старте. Запрещает кальки, термины без пояснения при первом употреблении, внутренние коды
  в прозе, вычурные обороты и фразы, непонятные читателю вне сессии; требует перечитать
  текст глазами читателя перед отправкой.
- **Skill `clarity-validator`** — валидация консистентности текста: 5 проверок + каталог
  12 синтетических паттернов. Загружается на «проверь консистентность», «валидация
  текста», «проверь на синтетику», «найди противоречия».
- **Skill `ai-prose-detector`** — редактирование художественной прозы по 6 методам.
  Загружается на «проверь текст на AI-паттерны», «анализ синтетичности прозы».
- **Skill `russian-style`** — 5 правил естественного русского. Загружается на «пиши
  по-русски естественно», «убери кальки», «это звучит как AI», «упрости для
  разработчиков», «проверь согласование».
- **Workflow `clarity-language:calque-sweep`** — разбор текстов на кальки в два шага:
  дешёвый проход собирает кандидатов, отдельная оценка решает по каждому со сверкой
  по списку решённых слов. На выходе файл-отчёт: глоссарий и места замены с фразами
  целиком. Два режима, режим по умолчанию не подставляется — `deep` разбирает только
  названные файлы, `full` идёт по всему репозиторию и запускается только явно.

## Разбор на кальки воркфлоу

```text
Workflow({name: "clarity-language:calque-sweep", args: {
  mode: "deep",
  files: ["docs/что-правили.md"],
  report_path: ".claude/calque-sweep-report.md"
}})
```

Спорные слова воркфлоу не решает за человека: случай «перевести или оставить
заимствование» попадает в отчёт отдельным разделом с вопросом. Это протокол
скилла `russian-style`, а не осторожность воркфлоу.

## Установка

```bash
claude --plugin-dir plugins/clarity-language
```

Или добавьте в настройки проекта/глобальные настройки Claude Code.

## Происхождение

Скиллы основаны на **First Principles Framework** (FPF, `https://github.com/ailev/FPF`):
аксиомы A.7 (Strict Distinction), A.10 (Evidence Graph), A.1.1 (BoundedContext),
A.11 (Ontological Parsimony). Правила `russian-style` выведены из реальных правок
рабочих текстов.

## Совместимость

- **clarity-validator** дополняет **functional-clarity**: первый держит ясность
  текстов, второй — ясность кода. Оба опираются на FPF.
