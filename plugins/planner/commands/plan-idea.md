Активируй скилл `product-discovery` с видом документа `idea` и выполни его порядок работы от начала до конца. Для этого вида скилл загружает `references/idea-mode.md`.

Разбор `$ARGUMENTS`:

- Свободный текст без читаемого пути — новый замысел: исходная формулировка сохраняется в документе дословно, вместе с источником.
- Путь к существующему файлу `IDEA-NNNN-<slug>.md` — продолжение или пересмотр этого замысла; сначала посмотри его состояние через `inspect`.
- Пустой аргумент — начни диалог с вопроса об исходной формулировке.

Значимые решения, включая решение об исходе, задавай через `AskUserQuestion` по протоколу скилла.

Успешный запуск всегда записывает результат в `ideas/IDEA-NNNN-<slug>.md`. После успешной записи в чате — только короткий итог по формату скилла: вид, путь и версия, два–четыре главных исхода, следующая команда, когда она есть. Следующую команду не выполняй сам. Полный документ в чат не дублируется.

Метод проработки живёт в скилле и его справочниках; не повторяй его здесь. При ошибке записи следуй разделу «Ошибка записи» скилла: подготовленное тело документа — запасной результат.
