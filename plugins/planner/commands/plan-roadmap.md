Активируй скилл `product-discovery` с видом документа `roadmap` и выполни его порядок работы от начала до конца. Для этого вида скилл загружает `references/roadmap-mode.md`.

Разбор `$ARGUMENTS`:

- Путь к `EPIC.md` — порядок живёт в том же каталоге: целевой файл `ROADMAP.md` рядом с гипотезой.
- Путь к каталогу гипотезы — возьми `EPIC.md` из него; если файла нет — остановись и попроси путь к гипотезе.
- Пустой аргумент — остановись и попроси путь к гипотезе: порядок без владельца результата не строится.

`allocate` для порядка не вызывается: имя файла фиксированное, номера выдачи нет. Родительская гипотеза передаётся в `validate-target` и `sync` флагом `--parent` — она обязана лежать в том же каталоге.

Значимые решения задавай через `AskUserQuestion` по протоколу скилла.

Успешный запуск всегда записывает результат в `epics/EPIC-NNNN-<slug>/ROADMAP.md`. После успешной записи в чате — только короткий итог по формату скилла: вид, путь и версия, два–четыре главных исхода, следующая команда, когда она есть. Следующую команду не выполняй сам. Полный документ в чат не дублируется.

Правила горизонтов, условия перехода и проверка готовности — в скилле; не повторяй их здесь. При ошибке записи следуй разделу «Ошибка записи» скилла: подготовленное тело документа — запасной результат.
