# /end-session — закрытие сессии (лёгкий протокол)

> Шаблон для код-репозиториев без сессионного процесса. Местозаполнитель
> `<каталог-сводов>` заменяется при установке (обычно `.claude/frameworks`).

Закрой сессию по четырём шагам.

## Шаг 1. Итог

Что сделано, что осталось. Пара строк.

## Шаг 2. Worked-evidence сводов

Привяжи события сессии к паттернам применявшихся сводов — журнал каждого
пакета: `<каталог-сводов>/<ID>/references/worked-evidence.md`. Якорь здесь —
обычно MR/коммит или файл.

1. **Закрой висящие исходы.** Записи с исходом `TBD` (включая прошлые сессии)
   подними списком: проставь исход (подтверждает / опровергает / показал
   границу) или явно отложи с причиной. Молча не пропускай.
2. **Ретроспектива сессии** (обязательна, даже если framework-apply не
   вызывался): какие паттерны каких сводов применялись или провалились
   напрямую? Допиши с меткой `direct`.
3. **Не дублируй.** Событие уже есть авто-записью framework-apply (тот же якорь,
   тот же пакет) — проставь исход в неё, дубль не создавай.
4. **Формат строки** (един для всех писателей, не переформулировать):

   ```
   - YYYY-MM-DD · <якорь: сессия | MR/коммит/файл> · ground|apply|direct · Паттерн N «имя» · что произошло (1-2 фразы) · исход: подтверждает / опровергает / показал границу / TBD
   ```

Правила: «никакие» — валидный ответ; в `DPF.md` не писать; опровержения ценнее
подтверждений — опровергающая запись уходит кандидатом на правку свода в бэклог.

пометкой почему.
