# tdd-master

Цикл красный–зелёный–рефакторинг как правило работы: реализация начинается
только после падающего теста. Плагин поставляет и сам метод, и исполнителя, и
правило, которое держит порядок фаз в сессии.

## Состав

| Компонент | Предметная роль |
|---|---|
| хук `SessionStart` | вносит в сессию правило: реализация только после падающего теста |
| скилл `tdd-master` | метод: порядок фаз, запреты, выбор справочника по стеку |
| агент `tdd-master` | пишет тесты; объём работы зависит от способа вызова |

Команд плагин не поставляет: цикл включает скилл или вызывающая роль.

## Как пользоваться

### Когда включается скилл

Скилл подключается сам, когда в запросе речь о написании или добавлении тестов,
о воспроизведении бага падающим тестом или о реализации новой функциональности.
Точные пусковые формулировки живут в самом скилле, страница их не повторяет.

### Два режима агента

| Вызов | Что делает |
|---|---|
| напрямую | весь цикл: падающий тест, затем минимальная реализация, затем рефакторинг |
| из другого агента | останавливается после красной фазы: создаёт файл тестов, возвращает список тестов; зелёную фазу делает вызывающая роль |

### Справочник по стеку

Стек определяется по файлам проекта, и от него зависит, какой справочник метода
подгружается. Справочники поставляются вместе со скиллом; точка входа —
`plugins/tdd-master/skills/tdd-master/SKILL.md`, а сами справочники лежат рядом
с ним:

| Найдено | Справочник |
|---|---|
| `pyproject.toml`, `conftest.py` | `references/frameworks/pytest.md` — pytest |
| `manage.py` | `references/frameworks/django.md` — Django |
| ничего из перечисленного | `references/TDD_GUIDE.md` — общий справочник по циклу |

Полный текст правил остаётся в справочниках, страница называет только их
назначение.

### Что цикл запрещает

- реализация без падающего теста;
- пропуск рефакторинга;
- тесты, которые проходят всегда;
- `raise Exception` вместо `pytest.fail()`;
- заглушки вместо своей бизнес-логики — только вместо внешних сервисов.

## Границы

- Цикл сам не запускается: команд у плагина нет, а хук лишь вносит правило в
  сессию.
- В делегированном режиме агент реализацию не пишет.
- Правка текста или промпта без наблюдаемого контракта тестом не покрывается:
  придумывать проверку ради красной фазы запрещено правилами проекта.
