# fpf-integration

First Principles Framework в проекте: четыре скилла, агент-гейт, два хука.

## Состав

| Компонент | Что делает |
|---|---|
| скилл `fpf-integration` | аудит решений, граф подтверждений, проверка альтернатив, механизм устаревания, чеклисты ролей |
| скилл `dpf-authoring` | шестифазный конвейер создания, доавторинга, переоценки и ремонта свода |
| скилл `dpf-apply` | резолв свода по уровням проект → пользователь → плагин, гейт свежести, режимы подготовки и применения, журнал применений |
| скилл `end-session-setup` | ставит в проект ритуал закрытия сессии |
| агент `dpf-gate` | проверяет допуск, свежесть, редакцию; возвращает план; инструментов записи нет |
| хук `SessionStart` | печатает карту доступных сводов, помечает протухшие; при пустом наборе молчит |
| хук `UserPromptSubmit` | до трёх подсказок по идентификатору `DPF-*`/`LPF-*` или ключевым словам карты |

Компетенций сам плагин не содержит: своды приходят из проекта,
пользовательского каталога или плагина-банка.

## Триггеры

| Скилл | Фразы |
|---|---|
| `fpf-integration` | «FPF», «добавь FPF в проект», «FPF audit», «проверь качество подтверждений» |
| `dpf-authoring` | «создай DPF», «доавтори DPF», «переоцени свод», «отремонтируй DPF» |
| `dpf-apply` | «примени компетенцию», `DPF-*`, `LPF-*`, «какие компетенции есть» |
| `end-session-setup` | «поставь end-session», «настрой worked-evidence» |

Точка входа перед работой со сводом — агент `dpf-gate`.

## Поиск сводов

```text
1. $PWD/.claude/frameworks
2. ~/.claude/frameworks
3. пути из ~/.claude/frameworks.paths
```

Префикс `plugin:` ограничивает поиск плагиновыми путями. Коды `resolve.py` для
одного свода: `0` — свод свеж, `1` — не найден, `2` — найден, но неактивен или
просрочен.

## Что появляется на диске

```text
<каталог сводов>/                      своды проекта (dpf-authoring)
<пакет>/references/package-adequacy-<дата>.md   отчёт переоценки
<пакет>/references/worked-evidence.md  журнал применений (dpf-apply)
.claude/commands/end-session.md        ритуал закрытия сессии
rules/frameworks.md или CLAUDE.md      раздел про своды, для репозитория с кодом
```

## Ограничения

- Без справочника FPF через MCP или локальной копии скилл останавливается;
  облегчённого режима нет.
- Опечатка или одна строка в своде правится точечно, конвейер для этого не
  запускается.
- Применение требует пары «свод × заявленное применение».
- `dpf-gate` возвращает план и отказ; читать свод, запускать конвейер и править
  файлы — не его полномочия.
- Текст свода в промпты не копируется: свод применяет резолвер.
- Отказ по свежести или редакции — результат работы гейта, свод нужно
  переоценить.
