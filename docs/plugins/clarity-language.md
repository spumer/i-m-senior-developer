# clarity-language

Проверка текстов: три скилла и хук. Файлов не пишет, возвращает отчёт в чат.

## Состав

| Скилл | Предмет | Результат |
|---|---|---|
| `clarity-validator` | технические документы: противоречия, смешение слоёв, выдуманные процессы, дрейф терминов — 12 паттернов | находки: тип, серьёзность, файл, цитата, диагноз, направление правки |
| `russian-style` | русский текст: кальки, номинализации, пустые антитезы, канцелярит, подставленное панибратство | правки формулировок |
| `ai-prose-detector` | художественная проза: 6 методов — дистанция, готовые метафоры, недостоверные детали, переобъяснение, механистичность, монотонность | диагнозы, без готового текста |

Хук `SessionStart` ставит правило времени записи: перечитать человекочитаемый
текст перед каждой записью. Запрещает кальки при наличии родного слова, термины
без пояснения при первом употреблении, внутренние коды в прозе, вычурные образы.

## Триггеры

| Скилл | Фразы |
|---|---|
| `clarity-validator` | «проверь консистентность», «валидация текста», «найди противоречия», «проверь на синтетику» |
| `russian-style` | «убери кальки», «это звучит как AI», «проверь русский стиль», «упрости текст для разработчиков» |
| `ai-prose-detector` | «проверь прозу на AI-паттерны», «редактура художественного текста» |

## Спорное слово

`russian-style` не решает сам, переводить термин или оставить заимствование:
выносит вопрос человеку, до решения пишет заимствование, принятое решение
записывает в лексикон проекта.

## Ограничения

- Фактическую правду текста ни один из трёх скиллов не проверяет.
- `clarity-validator` без списка файлов не угадывает область — спрашивает.
- `ai-prose-detector` настроен на психологический триллер и киберпанк, другие
  жанры требуют адаптации критериев; авторство «человек или ИИ» не определяет.
- Ясность кода — `functional-clarity`.
