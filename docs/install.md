# Установка и обновление

Эта страница для человека с установленным Claude Code, который хочет поставить
или обновить плагин из этого маркетплейса.

Выбрать плагин и узнать его назначение можно на [странице плагинов](plugins/index.md).

## Первая установка

В сессии Claude Code сначала один раз добавьте маркетплейс:

```text
/plugin marketplace add spumer/i-m-senior-developer
```

Затем установите выбранный плагин:

```text
/plugin install <имя-плагина>@i-m-senior-developer
```

## Следующий плагин

После добавления маркетплейса для каждого следующего плагина достаточно одной
команды установки:

```text
/plugin install <имя-плагина>@i-m-senior-developer
```

## Обновление

Обновите установленный плагин по его имени:

```text
/plugin update <имя-плагина>
```

После обновления перезапустите Claude Code: без перезапуска новая версия
плагина не применяется к текущей сессии.

## Проверка установки

Список установленных плагинов выводит команда:

```text
/plugin list
```

Если плагин не появился в списке или после установки не работает ожидаемое
поведение, откройте [разбор неполадок](troubleshooting.md).
