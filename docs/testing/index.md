# Проверка плагинов

Результаты конкретных прогонов — в [отчётах](../reports/index.md).

## Два вида проверки

| Команда | На какой вопрос отвечает | Стоимость |
|---|---|---|
| `claude plugin validate` | Плагин имеет допустимую структуру и может загрузиться? | бесплатно |
| `claude plugin eval` | Модель с этим плагином ведёт себя так, как требуется? | платно |

Первая читает манифест, схемы и frontmatter. Вторая запускает модель на реальных
запросах и оценивает трассу, финальный ответ и созданные файлы.

Структурная проверка не заметит, что скилл никогда не срабатывает на живом
запросе. Поведенческая проверка не заметит опечатку в манифесте. Нужны обе.

## Границы структурной проверки

Корень плагина проверяет преимущественно манифест. Frontmatter компонентов
проверяется только при отдельной передаче каталогов:

```bash
claude plugin validate <plugin> --strict
claude plugin validate <plugin>/commands --strict
claude plugin validate <plugin>/skills --strict
claude plugin validate <plugin>/agents --strict
```

`--strict` обязателен: без него отсутствующий `description` у скилла остаётся
предупреждением и код выхода равен `0`.

Измеренная граница: неизвестное поле во frontmatter команды не отклоняется даже
со `--strict`, хотя описание флага обещает отказ на нераспознанных полях.
Проверять договор команд этой командой нельзя.

## Какому плагину нужен свой eval-набор

Поведенческий набор обязателен, когда плагин обещает наблюдаемое поведение
модели: срабатывание скилла на живом запросе, маршрутизацию входа, запись файла,
порядок вызовов. Плагину, который поставляет справочное содержание и скрипты,
достаточно автоматических тестов на скрипты и ревью содержания.

По этому критерию собственный набор есть у `planner` — он заявляет маршрутизацию
продуктового входа. Основание и разбор границы — [решение 5](../decisions.md).

Из этого критерия следует и релизное правило: полный успешный прогон обязателен
для каждого затронутого плагина, у которого есть свой `evals/run.py`. Порог
строгий, понижать его вместо исправления поведения нельзя.
