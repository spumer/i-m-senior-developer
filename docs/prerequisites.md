# Что нужно

Эта страница для человека, который ещё не установил плагины и хочет проверить
среду заранее.

## Claude Code

Общая минимальная версия Claude Code для всего маркетплейса не установлена:
ни манифесты плагинов, ни манифест маркетплейса не объявляют такую границу.
Узнать версию своей среды можно командой:

```bash
claude --version
```

Проверенная среда конкретного плагина не становится общим минимальным
требованием. Среду, в которой наблюдали поведение `planner`, задаёт его набор
проверок: как его запустить, сказано в [инструкции проверки](testing/running.md).

## Python

Проверить доступность Python можно командой:

```bash
python3 --version
```

`python3` напрямую вызывают хуки `planner` и `fpf-integration`. Это ограничение
не относится ко всем хукам маркетплейса: у остальных плагинов способ запуска
может быть другим.

## Ограничение planner по модели

Автоматическая маршрутизация продуктового входа в проработку подтверждена на
`opus`. На `sonnet` она в наблюдённом прогоне не наступала. Это ограничение
плагина, а не проверки; условия наблюдения задаёт его набор проверок, и
воспроизводится оно прогоном этого набора.

Если среда готова, перейдите к [установке и обновлению](install.md). Если
плагин уже не дал ожидаемого результата, откройте [разбор неполадок](troubleshooting.md).
